# Archivos de marca

Logo vectorial original y tipografía Skyload pendientes. El componente `src/components/Logo.astro` combina un cubo SVG nativo, construido a partir de la guía suministrada, con un wordmark provisional en Syncopate.

Versiones listas: positivo, negativo (`negative`), sin descriptor (`compact`) y cubo (`Cube.astro`). El footer usa la versión positiva sobre crema. Favicon en `public/favicon.svg`; logo para datos estructurados en `public/brand/logo.svg`.

Sustituir el wordmark provisional por el SVG autorizado preservando área de seguridad, proporción y nombre accesible. El sello del Club Cámara debe venir del archivo oficial mencionado en el PDF; no se ha recreado ni afirmado la pertenencia sin ese material.
